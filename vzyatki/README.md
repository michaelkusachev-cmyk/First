# Цена коррупции

Простой статический сайт: таблица дел чиновников с суммами взяток/ущерба, поиск, фильтры, сортировка и общая сумма.

- `index.html` — страница
- `data.js` — **данные** (здесь добавляются новые дела)
- `app.js` — логика таблицы, `style.css` — оформление

Сборка не нужна — достаточно открыть `index.html` в браузере или залить папку на любой хостинг (GitHub Pages, Netlify и т.п.).

## Правила для записей
- У каждой записи должна быть ссылка на источник.
- Указывайте статус: `приговор`, `суд` или `обвинение` — это защищает от исков о клевете.
- Валюту пересчитывайте в рубли, исходную сумму пишите в `note`.
