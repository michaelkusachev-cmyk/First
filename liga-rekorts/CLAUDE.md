## Как делать типовые задачи

**Добавить пару.** В `assets/league.js` → `PAIRS.<id>` дописать `{a:'Имя Фамилия', b:'Имя Фамилия'}`. Игрок без партнёра — `{a:'Имя Фамилия'}` (без `b`): на сайте покажется «Ищет партнёра» и ссылка «Стать партнёром» (открывает форму заявки с текстом «Хочу в пару к …»). id дивизионов: `w` Женский, `am` Любитель, `ma` Мастер, `pro` Профи, `40` 40+. Страницы обновятся сами. Потом — `build-standalone.ps1` и пересъёмка постов.

**Изменить вместимость дивизиона.** Три места: `pairs:N` у дивизиона в `LEAGUE.divs` (`league.js`), `pairs=N` в `$divs` (`build-pages.ps1`), `CAP` в `index.html`. Плюс тексты «84 пары в лиге», «по 16–20 пар» (главная), «В дивизионах по 16 пар, в Мастере — 20» и «84 пары в борьбе» (`build-pages.ps1`). Затем `build-pages.ps1` и `build-standalone.ps1`.

**Добавить матч / результат.** `MATCHES` в `league.js`: `{div:'pro', date:'2026-12-12', time:'19:00', court:'Корт 2', stage:'Чемпионат', a:'Имя Фамилия / Имя Фамилия', b:'…', score:'6:4, 3:6, 10:8'}`. Без `score` — в «Расписание», со счётом — в «Результаты» и таблицу.

**Добавить фотоальбом.** Фото в `media/<id>/`, запись в `ALBUMS` (формат в комментарии в `league.js`).

**Пересобрать страницы:** `powershell -ExecutionPolicy Bypass -File build-pages.ps1`
**Пересобрать автономные HTML и архивы:** `powershell -ExecutionPolicy Bypass -File build-standalone.ps1`

**Посты «Состав дивизиона».** Рендер headless Chrome (путь к Chrome свой):
`chrome --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=1080,1350 --virtual-time-budget=8000 --screenshot=out.png "file:///<путь>/соцсети/sostav.html?div=pro"`
В сетке помещается 16 карточек; у одиночки вместо подписи пунктирный кружок «?» (владелец просил без лишнего текста). Плашка внизу — «ИДЁТ ПРИЁМ ЗАЯВОК» (если мест нет и одиночек нет — «СОСТАВ НАБРАН»). Если в Мастере станет больше 16 пар — нужен второй слайд или формат 1080×1920.

**Посмотреть сайт локально.** Из папки проекта: `python -m http.server 8765` → http://localhost:8765 (или preview из `.claude/launch.json`). Файл через file:// тоже открывается, но 3D и часть браузеров капризничают.

**Публикация.** Своего домена и хостинга пока нет. `Лига_РеКортс_сайт.zip` — готовый архив для любого статического хостинга (Netlify, GitHub Pages, Яндекс Object Storage, обычный хостинг; Тильда не подходит). Автономные HTML (`Лига_РеКортс_HTML.zip`) — для показа дизайна без сервера.

## Подводные камни

- Скрипты `.ps1` с кириллицей хранить в **UTF-8 с BOM**, иначе Windows PowerShell 5.1 читает их как ANSI и падает.
- В PowerShell `@(a, b + c)` — запятая сильнее плюса, сложение брать в скобки.
- Класс `.day` занят календарём главной; на странице расписания используются `.sday`, `.sday-date`.
- Сетки на телефоне — `minmax(0,1fr)`, иначе длинные имена распирают страницу.
- Скриншоты телефона: окно Chrome не уже ~500 px — снимать через iframe 390 px или эмуляцию.
