# Travel.laboratory

Сайт индивидуальных путешествий (Новосибирск). Тема оформления — «Табло».

- `index.html` — все разделы лендинга
- `assets/styles.css` — стили
- `assets/app.js` — меню, табло, квиз, календарь, игра «Собери маршрут», заявка

Сборка не нужна: это обычный HTML. Открыть `index.html` в браузере или выложить на любой хостинг (например, GitHub Pages).

Плейсхолдеры в квадратных скобках (раздел «Горящие предложения») нужно заменить реальными предложениями.

## Горящие билеты

Раздел «Горящие предложения» берёт билеты из `assets/deals.json`.
Каждый день в 04:07 по Новосибирску робот (`.github/workflows/deals.yml`) запускает
`scripts/update_deals.py`: билеты в одну сторону из Новосибирска за рубеж до 20 000 ₽
с вылетом в ближайшие 45 дней, самый дешёвый на каждое направление, до 6 штук.
Прошедшие вылеты сайт скрывает сам.

Чтобы робот заработал:
1. Зарегистрироваться на travelpayouts.com (бесплатно), подключить программу Aviasales
   и скопировать API-токен в разделе «Инструменты → API».
2. В GitHub: Settings → Secrets and variables → Actions → New repository secret,
   имя `TRAVELPAYOUTS_TOKEN`, значение — токен.
3. Робот работает только в основной ветке репозитория.

## Домен nsktour.ru

Сайт публикуется через GitHub Pages (Settings → Pages → ветка main, папка / root),
файл `CNAME` в корне указывает домен nsktour.ru.

Записи DNS у регистратора (reg.ru / nic.ru) для nsktour.ru:

| Тип   | Имя (хост) | Значение                     |
|-------|------------|------------------------------|
| A     | @          | 185.199.108.153              |
| A     | @          | 185.199.109.153              |
| A     | @          | 185.199.110.153              |
| A     | @          | 185.199.111.153              |
| CNAME | www        | michaelkusachev-cmyk.github.io. |

Старые A-записи и записи «парковки» регистратора для @ и www удалить.
После того как домен откроется, в Settings → Pages включить «Enforce HTTPS».
