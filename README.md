# Travel.laboratory

Сайт индивидуальных путешествий (Новосибирск). Тема оформления — «Табло».

- `index.html` — все разделы лендинга
- `assets/styles.css` — стили
- `assets/app.js` — меню, табло, квиз, календарь, игра «Собери маршрут», заявка

Сборка не нужна: это обычный HTML. Открыть `index.html` в браузере или выложить на любой хостинг (например, GitHub Pages).

Плейсхолдеры в квадратных скобках (раздел «Горящие предложения») нужно заменить реальными предложениями.
