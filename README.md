# Travel.laboratory

Сайт индивидуальных путешествий (Новосибирск), travelaboratory.ru.
Тема оформления — «Табло», палитра «Терракота»: шрифты Lora (заголовки) и Golos Text (всё остальное).

- `index.html` — все разделы лендинга
- `assets/styles.css` — стили; цвета и шрифты — переменные в начале файла (`:root`)
- `assets/app.js` — меню (и список «Ещё»), табло, квиз, календарь, игра «Собери маршрут», заявка, ленивая загрузка видео
- `assets/video/` — фоновые видео (первый экран, карточки направлений, «Горящие предложения»)

Сборка не нужна: это обычный HTML.

## Где живёт сайт и как обновляется

Сайт лежит на хостинге SpaceWeb, в папке `travelaborator_ru/public_html`.
Источник — ветка **`claude/clever-mayer-jmzc87`** этого репозитория: всё, что попадает в неё, через сутки
(или сразу, если запустить задание вручную) оказывается на сайте.

На хостинге в «Панель → Crontab» раз в сутки (0:00 по серверу) запускается команда вида:

    (curl -fsS https://raw.githubusercontent.com/michaelkusachev-cmyk/First/claude/clever-mayer-jmzc87/scripts/sync_hosting.sh | sh) > $HOME/sync.log 2>&1

Она каждый раз берёт свежую версию `scripts/sync_hosting.sh` из GitHub, поэтому сам скрипт на хостинг
заливать не нужно. Скрипт:

1. Читает новую `index.html` и докачивает видео, на которые она ссылается и которых на хостинге ещё нет.
   Пока все видео не скачаны, страницу не трогает (GitHub иногда отдаёт свежий файл с задержкой).
2. Обновляет страницы, стили, скрипт, `deals.json`, значок и картинку для соцсетей.
3. Удаляет из `assets/video` ролики, на которые страница больше не ссылается.

Чтобы увидеть изменения сразу, в Crontab временно ставят `*` во все поля времени, ждут пару минут
и возвращают минуту `0` и час `0`.

### Как менять видео

Браузеры хранят видео 30 дней (`.htaccess`), а скрипт качает только новые файлы. Поэтому заменённое видео
всегда кладётся **под новым именем** (`asia-v2.mp4` → `asia-v3.mp4`), а в `index.html` меняется ссылка.

К каждому видео нужны пять файлов: `имя.mp4`, `имя.webm`, `имя-small.mp4`, `имя-small.webm` (до 820 px
ширины экрана) и заставка `имя.jpg`. Ширина большого — 1280 px, длина — 6–8 секунд, без звука.
На карточках левую часть закрывает текст, поэтому главное в кадре лучше держать справа.

Источники видео: съёмки команды, ролики с разрешения авторов (Оман — @erfanadventure, Сейшелы, Европа — Лувр)
и бесплатный сток Mixkit (Турция, «Горящие предложения»; лицензия разрешает коммерческое использование
без указания автора).

## Заявки с сайта → Telegram

Форма «Куда хотите поехать?» отправляет заявку в `lead.php`, а он — в Telegram через бота @TravelLaboratory_bot.
Токен бота и `chat_id` получателя лежат на хостинге в `travelaborator_ru/tg-config.php` — рядом с `public_html`,
не внутри неё (образец — `tg-config.example.php`; сам файл с токеном в репозиторий не добавлять).
Если файла нет или Telegram не ответил, форма, как раньше, готовит текст заявки и открывает Telegram.
Защита от спама: скрытое поле-ловушка и не больше 5 заявок в час с одного адреса.

## Горящие билеты

Раздел «Горящие предложения» берёт билеты из `assets/deals.json`; прошедшие вылеты сайт скрывает сам.
Сейчас билеты обновляются каждый день со страницы aviasales.ru/hottickets/ovb:

    NODE_PATH=$(npm root -g) node scripts/hot_aviasales.js > /tmp/hot.json
    python3 scripts/pick_hot.py /tmp/hot.json

Правила выбора: 2 билета за рубеж и 1 по России, до 20 000 ₽; страны (для России — города)
последних двух дней по возможности не повторяются.

Есть и запасной робот `.github/workflows/deals.yml` (`scripts/update_deals.py`, данные Travelpayouts):
он работает только в основной ветке репозитория и только с секретом `TRAVELPAYOUTS_TOKEN`
(Settings → Secrets and variables → Actions). Токен берётся на travelpayouts.com → программа Aviasales →
«Инструменты → API».

## Прочие страницы и файлы

- `privacy.html` — политика обработки персональных данных; ссылка на неё — в подвале и в галочке согласия формы.
- `404.html` — страница «Рейс отменён» для несуществующих адресов (подключена в `.htaccess`).
- `.htaccess` — настройки Apache на SpaceWeb: страница 404, типы видео, сроки кэша.
- `robots.txt`, `sitemap.xml` — для Яндекса и Google.
- `CNAME` — остался от GitHub Pages, для SpaceWeb не нужен.
- Яндекс.Метрика: в `index.html` и `privacy.html` перед `</head>` есть закомментированный блок —
  заменить `00000000` на номер счётчика и снять комментарий.

Если куплен и nsktour.ru — у регистратора включить для него переадресацию (301)
на https://travelaboratory.ru, отдельный сайт для него не нужен.
