# Работа с сайтом sibhl.ru/padel (падел-лига РЕ:КОРТС)

Отвечай владельцу по-русски, коротко. Владелец часто пишет с телефона: присылает фото, имена игроков, правки текстов.

## Границы

- Работаем **только** с папкой `padel-sibhl/` (сайт sibhl.ru/padel) и инструментами `tools/padel-build/`, `tools/padel-photo/`.
- Основной сайт sibhl.ru (корень репозитория) и папки `liga-rekorts/`, `tury/`, `scripts/`, `assets/` **не трогать**. `liga-rekorts/` — старая версия, к живому сайту отношения не имеет.
- Ветка: **`claude/youthful-goldberg-ogf99b`**. Все коммиты — в неё. Если сессия стартовала на другой ветке: `git fetch origin claude/youthful-goldberg-ogf99b && git checkout claude/youthful-goldberg-ogf99b`.

## Как устроен сайт

Собранный React/Vite, исходников нет. Все данные вшиты в `padel-sibhl/assets/index-R*.js`. Рабочий файл — тот, на который ссылается `padel-sibhl/index.html` (не самый новый по имени — смотри ссылку).

Внутри сборки:
- `K=[{id:`w`,...},...]` — дивизионы: `w` Женский, `am` Любитель, `ma` Мастер, `pro` Профи, `40` 40+ (min/max рейтинга, тексты `lead`, `levels`).
- `q={am:[{a:`Имя Фамилия`,b:`Имя Фамилия`},{a:`Имя`}],40:[...],...}` — составы. Пара = `{a,b}`, игрок без пары = `{a}`. Счётчики «N из 16 пар», «ищут партнёра», «игроков в составах» считаются из `q` автоматически.
- `PHO={"Имя Фамилия":`/padel/img/slug.jpg`,...}` — фото игроков. Ключ должен **точно** совпадать с именем в `q`. На сайте фото — кружок 40 px.

## Любая правка = новая сборка (JS кэшируется на год)

Одной командой (копия текущей сборки → правки → новое имя → `index.html` → строка в журнал README):

```bash
python3 tools/padel-build/new_build.py --log "Мастер: добавлен Иван Иванов (без партнёра)" \
  --replace '{a:`Роман Червяков`}]' '{a:`Роман Червяков`},{a:`Иван Иванов`}]'
```

- `--replace OLD NEW` можно повторять; каждый OLD должен встречаться **ровно 1 раз** (иначе скрипт ничего не пишет — расширь контекст OLD).
- `--pho "Имя Фамилия" slug` — добавить/обновить фото в `PHO`.
- `--dry-run` — проверить без записи.
- Перед правкой найди точный фрагмент: `grep -o '.\{80\}Иванов.\{80\}' padel-sibhl/assets/<текущая>.js`.
- Игрок может быть в двух дивизионах — проверь все вхождения и уточни у владельца, где менять.

## Фото игроков (единый стиль)

```bash
pip install -r tools/padel-photo/requirements.txt   # один раз за сессию
python3 tools/padel-photo/padel_photo.py <исходник> <slug>      # -> padel-sibhl/img/<slug>.jpg
python3 tools/padel-build/new_build.py --log "Фото игрока: Имя Фамилия" --pho "Имя Фамилия" <slug>
```

- Скрипт убирает фон (rembg, модель `birefnet-portrait`, при первом запуске качает ~900 МБ), ставит единый серо-голубой фон, кадрирует по голове, 240×240 JPEG.
- **Покажи результат владельцу** (посмотри картинку сам и опиши/пришли) до выкладки, если фото сложное: групповое, издалека, лицо в профиль.
- Владелец присылает фото как вложение; имя файла до тебя не доходит — фамилию берём из сообщения. Полное имя ищи в составах `q`. По лицу людей не определять.
- slug — фамилия латиницей (`tuev`, `gubanov`); при совпадении фамилий — `rogoza-yana`.
- **Замена уже выложенного фото — под новым именем** (`kornilov-2.jpg`): картинки кэшируются браузерами на месяц.

## Выкладка и проверка

```bash
git add padel-sibhl tools && git commit -m "padel-sibhl: <что сделано>" && git push origin claude/youthful-goldberg-ogf99b
```

После пуша GitHub Actions (`.github/workflows/padel-deploy.yml`) сам заливает изменённые файлы `padel-sibhl/` на хостинг по FTP, обычно за 10–60 с. Вручную ничего не заливать.

Проверка: `curl -s "https://sibhl.ru/padel/?nc=$RANDOM" | grep -o 'index-R[^"]*\.js'` — должна быть новая сборка; фото — `curl -sI https://sibhl.ru/padel/img/<slug>.jpg`. Страницы: `/padel/`, `/padel/igroki`, дивизионы `/padel/zhenskiy`, `/lyubitel`, `/master`, `/profi`, `/40-plus`.

Если хостинг недоступен из окружения — проверь, что workflow в GitHub Actions прошёл зелёным, и скажи владельцу открыть сайт.

## Мелочи

- Файлы в `padel-sibhl/` — байт в байт (см. `.gitattributes`), без CRLF и BOM. `new_build.py` пишет корректно.
- Журнал изменений — `padel-sibhl/README.md` (раздел «Журнал»), `new_build.py` дописывает его сам.
- Тексты для поисковиков страниц задаются в сборке вызовами `bn(`Заголовок`,`Описание`,`/путь`)`.
