# Падел-лига РЕ:КОРТС — сайт на sibhl.ru/padel

Копия того, что лежит на хостинге sweb в папке `padel` (это **собранный** сайт React/Vite, исходников здесь нет).
Данные (составы `PAIRS`, дивизионы, матчи) вшиты в `assets/index-R*.js`; рабочая сборка — та, на которую ссылается `index.html`.

Правки вносятся прямо в сборку: копия текущего `index-*.js` с новым именем (JS кэшируется браузером на год)
и замена ссылки в `index.html`. На хостинг заливать только изменённые файлы.
